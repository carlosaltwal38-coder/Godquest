# GodQuest: Light vs Darkness

An interactive biblical-themed battle game where you choose a hero and defeat demons using wisdom and knowledge.

## How to Play

1. Enter your name
2. Select your biblical hero (Jesus, David, Moses, or Samson)
3. Battle darkness by answering trivia questions
4. Gain XP and coins for victories
5. Chat with other players in the global chat room

## Game Features

- 🎮 **Hero Selection** - Choose from 4 biblical heroes
- ⚔️ **Battle System** - Answer questions to defeat enemies
- 💬 **Chat System** - Global chat and in-game battle dialogue
- 📊 **Progression** - Earn XP and coins for victories
- 🎨 **Dark Theme** - Beautiful purple and blue color scheme
